# README Style Guide

## Common Mistakes

- **No install steps** - Never assume setup is obvious
- **No examples** - Show, don't just tell
- **Wall of text** - Use headers, tables, lists
- **Stale content** - Add "last reviewed" date
- **Generic tone** - Write for YOUR audience

## Prose Quality

Prose quality is handled by the parent plugin: write Korean prose with the `korean-writing` skill from the start, and polish existing text with `humanize-korean`. (Upstream points to a `writing` skill that is not part of this plugin.)
