# 한국어 문서 검사

편집 훅은 방금 쓴 부분만 본다. 이 명령은 이미 저장돼 있는 파일을 통째로 같은 기준에 넣는다.
판정 코드와 메시지는 훅과 같다.

## 할 일

1. 검사한다. 인자가 있으면 그 경로로, 없으면 이번 대화에서 고친 `.md` 로 아래를 돌린다.

   ```bash
   "${CLAUDE_PLUGIN_ROOT}/scripts/check.sh" $ARGUMENTS
   ```

   고친 `.md` 도 없으면 어떤 파일을 볼지 묻고 멈춘다. 검사할 대상을 짐작하지 않는다.

2. 걸린 항목을 그대로 옮기고 그 자리를 보여 준다. 보고에 붙은 `N행` 과 발췌가 위치다. 규칙마다 셋까지만
   붙으므로 「외 N곳」이 있으면 파일에서 나머지를 찾는다. 코드는 `K1` 부터 `K10` 까지다.

3. 고칠지 묻는다. 고치라고 하면 `korean-writing` 스킬의 규칙대로 그 자리만 고친다.
   문장을 짧게 자르지 말고 표현만 바꾼다. 뜻과 격식과 사실은 그대로 둔다.

4. 고쳤으면 같은 명령을 다시 돌려 통과를 확인한다.

## 걸렸는데 고치지 않아야 할 때

계약서·약관·법률 문서이거나 나쁜 예를 일부러 싣는 규칙 문서라면 검사 대상이 아니다.
파일 첫 열 줄 안에 줄 하나로 `<!-- korean-writing: ignore -->` 를 넣으면 다시 알리지 않는다.
그 줄이 본문 안에 인용으로 들어간 것은 표시로 보지 않는다.

세션 전체를 끄려면 `KOREAN_WRITING_HOOK_DISABLED=1` 이고, 플러그인 설정에서 `edit_check` 를 꺼도 된다.
