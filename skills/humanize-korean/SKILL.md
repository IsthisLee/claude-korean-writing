# 한국어 윤문 — 단일 패스

번역기를 갓 거친 듯한 글을 **원래 한국어로 쓴 글**처럼 다듬는다. **사실은 한 글자도 바꾸지 않고** 문체·리듬·표현만 손본다.

## 0. 시작 전 확인

**라우팅.** 아직 쓰지 않은 글이면 이 스킬을 쓰지 않는다. `korean-writing`로 처음부터 제대로 쓴다. 이 스킬은 **이미 있는 글을 고치는** 용도다.

책 분량 원고는 출발점으로만 쓴다. 긴 글의 편집 판단은 사람이 한다.

**민감 텍스트.** 이 세션 밖의 모델이나 외부 서비스로 원문을 보내는 경로가 섞여 있으면, 고객명·계약 금액·개인정보·급여·비밀키가 든 글은 보내지 않는다. 확신이 없으면 이 세션 안에서 처리하거나 먼저 가린다.

## 1. 절차 — 한 번에 끝낸다

1. **읽는다.** 한글 5,000자를 넘으면 논리 단위로 나눠 구간별로 돌린다. 긴 글을 한 번에 머릿속에 담고 자기 점검까지 하려 들지 않는다.
2. **찾는다.** `../../references/quick-rules.md`(압축 룰북)로 훑는다. 애매하거나 근거가 필요한 것만 `../../references/taxonomy.md`(전체 패턴 목록)에서 확인한다.
3. **고친다.** 찾은 구간만 손본다. 전체를 다시 쓰지 않는다. 고유명사·숫자·날짜·단위·직접 인용은 **글자 그대로** 유지한다.
4. **점검한다.** `quick-rules.md`의 자기 점검 항목을 돌린다. **변경률이 50%를 넘으면 결과를 내놓지 말고 사용자에게 알린다.** 그건 윤문이 아니라 재작성이다.
5. **돌려준다.** 다듬은 글에 이 둘을 붙인다.
   - 한 줄 상태 — 변경률 추정과 등급(A~D)
   - 주요 교정 3~6개를 `전 → 후`로

## 2. 어기면 되돌린다

1. **의미는 불변이다.** 사실·주장·숫자·날짜·고유명사·인용은 100% 보존한다.
2. **근거가 있어야 고친다.** `quick-rules.md`나 `taxonomy.md`의 패턴에 걸리는 구간만 손본다. **내가 다르게 썼을 것 같다는 이유로 고치지 않는다.**
3. **장르와 문체는 그대로 둔다.** 칼럼이 에세이가 되지 않고, 보고서가 블로그 말투로 흐르지 않는다. 격식체는 격식체로 남는다.
4. **과잉 교정 금지.** 변경률 30%가 넘으면 경고 신호다. 50%를 넘으면 멈추고 다시 생각한다.

## 3. 목적을 이렇게 말하지 않는다

**"AI 탐지기 우회", "탐지 회피", "AI가 썼다는 걸 숨기기"로 설명하지 않는다.** 실제 목적은 **어색한 번역투를 자연스러운 한국어로 고치는 것**이고, 누가 초안을 썼는지와 무관한 정당한 품질 개선이다.

## 4. 이 스킬의 범위 밖

8,000자가 넘거나 정확도가 특히 중요한 글은 단일 패스로 부족하다. 탐지·재작성·충실도 검토를 분리한 다단계 리뷰가 낫다. 그건 이 스킬이 제공하지 않는다.
