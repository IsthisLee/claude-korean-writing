# 편집 검사 훅이 짚은 자리가 같은 턴에 고쳐지는가

검사 훅은 편집을 되돌리지 않습니다. 걸린 항목을 stderr 로 알리고 종료 코드 2 로 끝납니다. Claude Code 는 PostToolUse 훅이 종료 코드 2 로 끝나면 그 stderr 를 system reminder 로 Claude 에게 보여 주고 같은 턴에 반응하게 합니다([hooks 문서](https://code.claude.com/docs/en/hooks)). 이 실험은 그 알림을 받은 Claude 가 실제로 고치는지 봅니다.

## 방법

AI 티가 든 공지 초안([prompt.txt](./prompt.txt))을 `notice.md` 로 저장해 달라고 부탁합니다. 초안은 검사기에서 K1 줄표 4개, K6 승패 의인화 2회, K7 사물 의인화 2회로 걸립니다. 플러그인을 `--plugin-dir` 로 켠 쪽과 끈 쪽을 3회씩 빈 임시 폴더에서 돌리고 개인 설정과 MCP 는 불러오지 않습니다. 훅의 알림은 stream-json 에 찍히지 않아서 판정은 마지막 파일을 같은 검사기에 다시 넣어 합니다.

```bash
docs/experiments/hook-loop/run.sh 3 claude-sonnet-5
```

## 결과 (2026-09-11, claude-sonnet-5)

| 조건         | 도구 순서      | 마지막 파일에 남은 걸림 |
| ------------ | -------------- | ----------------------- |
| 플러그인 켬 1 | Write → Edit   | 없음                    |
| 플러그인 켬 2 | Write → Edit   | 없음                    |
| 플러그인 켬 3 | Write → Edit   | 없음                    |
| 플러그인 끔 1 | Bash → Write   | K1·K6·K7                |
| 플러그인 끔 2 | Write          | K1·K6·K7                |
| 플러그인 끔 3 | Write          | K1·K6·K7                |

켠 쪽은 세 번 모두 초안을 먼저 그대로 저장했고 훅이 걸린 뒤 `Edit` 한 번으로 걸린 항목을 다 고쳤습니다. Claude 가 남긴 말도 같습니다. 첫 실행에서는 "Write 훅이 AI 티 패턴(줄표 삽입구, 승패·사물 의인화)을 지적해서 지적된 표현만 고쳐서 다시 저장할게요" 라고 말한 뒤 고쳤습니다. 끈 쪽은 세 번 모두 초안 그대로 저장하고 끝났습니다.

1회 비용은 켠 쪽이 약 0.10달러, 끈 쪽이 약 0.06달러였습니다. 켠 쪽은 고치는 턴이 한 번 더 있어서 더 듭니다.

## 한계

훅이 짚은 것만 고칩니다. 초안의 「갈리는 축은 일정이 아니라 결입니다. 두 문제는 레이어가 다릅니다」는 켠 쪽 결과물 셋에 모두 남았습니다. K2 가 세는 형태는 `축이·축은·축을·축으로`, `갈래`, `결이 다르`·`결은 다르`, `레이어` 이고 임계는 3회입니다. 이 문장에서 세어지는 것은 `축은` 과 `레이어` 둘뿐입니다. `결입니다` 는 `결과`·`결정` 같은 말과 섞이지 않도록 일부러 세지 않는 형태입니다. 임계를 옮기려면 실제 문서의 오탐부터 재야 해서 이 실험으로 바꾸지는 않았습니다.

표본은 조건마다 셋이고 모델은 하나입니다. 이 조건에서 이 동작이 되풀이됐다는 기록이고 확률을 잰 것은 아닙니다.
