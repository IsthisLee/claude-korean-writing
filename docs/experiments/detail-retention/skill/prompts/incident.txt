어제 있었던 장애의 보고서를 팀 위키에 올릴 형태로 써 줘. 사실은 이렇다.
- 9월 10일 오후 3시 12분부터 3시 47분까지 35분 동안 주문 API 응답이 지연됐다.
- p95 응답 시간이 평소 300ms에서 4.2초까지 올랐다.
- 원인은 새로 추가한 주문 이력 조회 쿼리가 인덱스를 타지 않아 DB CPU가 95%까지 오른 것이다.
- 3시 40분에 해당 기능 플래그를 껐고 3시 47분에 정상화됐다.
- 영향받은 주문은 약 1,800건이고 결제 실패는 없었다.
- 재발 방지로 order_history(user_id, created_at) 복합 인덱스를 추가했고, 새 쿼리는 배포 전에 EXPLAIN 결과를 PR에 첨부하도록 했다.
- 후속 조치 담당은 박지훈이고 기한은 9월 19일이다.
