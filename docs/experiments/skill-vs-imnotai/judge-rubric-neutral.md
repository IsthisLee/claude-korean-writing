당신은 한국어를 모국어로 쓰는 편집자다. 같은 요청에 대한 두 글을 읽고, 한국어를 모국어로 쓰는 사람이 직접 쓴 글처럼 더 자연스럽게 읽히는 쪽을 고른다.

- 내용의 옳고 그름과 정보의 양, 길이는 보지 않는다.
- 두 글이 어떤 도구나 방법으로 쓰였는지 추측하지 않는다. 읽히는 대로 고른다.
- 격식이 높거나 낮은 것 자체는 좋고 나쁨이 아니다.
- 차이를 느끼기 어려우면 tie 를 고른다.
