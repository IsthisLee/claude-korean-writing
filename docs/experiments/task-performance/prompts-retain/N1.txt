아래 회의 결과를 팀에 공유할 공지로 정리해줘.

- 결제 모듈 v3 배포는 4월 18일 화요일 오전 2시부터 4시까지다. 담당은 박수현.
- 배포 중 결제 API 는 읽기 전용이 된다. 신규 주문은 큐에 쌓이고 배포 후 순차 처리한다.
- 롤백 기준은 오류율 2% 초과이고 판단은 15분 안에 한다. 롤백 담당은 이정우.
- 기존 v2 엔드포인트는 6월 30일까지 유지하고 7월 1일에 닫는다.
- 연동 팀은 4월 11일까지 테스트 계정으로 호환성 확인 결과를 회신해야 한다.
- 문의는 #payment-v3 채널로 받는다. 배포 당일에는 슬랙 대신 전화로 연락한다.

도구를 쓸 수 없다. 파일을 찾거나 명령을 돌리지 말고 위에 준 것만으로 바로 답하라.
