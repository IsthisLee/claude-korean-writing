normalize_path(p) -> str
  파일 시스템을 건드리지 않고 문자열만으로 경로를 정리한다.
  "." 은 버리고 ".." 은 앞 조각을 지운다. 연속된 슬래시는 하나로 줄인다.
  절대 경로면 맨 앞 "/" 를 지키고 루트 위로 올라가는 ".." 은 무시한다.
  상대 경로에서 위로 올라가는 ".." 은 남긴다. 결과가 비면 절대 경로는 "/", 상대 경로는 "." 이다.
  끝의 슬래시는 지운다.
